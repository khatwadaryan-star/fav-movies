# What is this?
This is a personal movie-recommendation website that highlights my favorite films that I believe everyone should watch. It includes a Home page that introduces the site, the main Movies page with posters and titles, and an About page with my personal introduction and contact information.
# Why does it exist?
In today's world, people have become overwhelmed by an abundance of streaming and algorithm-suggested options for movies. A curated, human-driven recommendation cuts through that and offers a personal, meaningful suggestion for movies. The intended audience are movie lovers, casual viewers looking for something new to watch, or people looking for personal recommendations.
# What tools did I use?
* HTML & CSS - To build the structure and design of the site.
* Visual Studio Code - The code editor used to write the code for the site.
* GitHub & GitHub Pages - The tool used to deploy the written code into a live site.
* Microsoft Copilot - Used to assist with resolving any errors I come across while writing the code.
